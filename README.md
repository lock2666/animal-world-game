# 🌍 عالم الحيوانات — ثلاث ألعاب تعليمية للأطفال

ثلاث ألعاب تفاعلية ممتعة لتعليم الأطفال عن الحيوانات، من إعداد الطالب **عبدالملك الطلحي — الصف 2/1**.

## 🎮 الألعاب

| اللعبة | الوصف |
| --- | --- |
| 🏠 أين يعيش الحيوان؟ | اسحب الحيوان إلى موطنه الصحيح (الصحراء، الغابة، البحار، الأنهار، العشب) |
| 🧩 تركيب أشكال الحيوانات | اضغط على قطعتين لتبديلهما وركّب صورة الحيوان من 9 قطع |
| 🍎 ماذا يأكل الحيوان؟ | اختر الطعام المفضل لكل حيوان من بين 26 حيواناً |

## ✨ المميزات

- 🔊 **تعليق صوتي بشري طبيعي بالعربية** — تشجيع وترحيب ومعلومات عن كل حيوان (181 مقطعاً صوتياً مدمجاً داخل الصفحة)
- 🌐 يعمل **بدون إنترنت** بعد فتح الصفحة (كل الأصوات والخطوط محمّلة أو مضمّنة)
- 📱 تصميم متجاوب يعمل على الجوال واللوح والحاسوب — بالسحب واللمس والنقر
- ⭐ نظام نجوم ونقاط يحفّز على الإجابة الصحيحة من أول محاولة
- 🎉 مؤثرات احتفالية (قصاصات ملونة، نغمات، اهتزاز)
